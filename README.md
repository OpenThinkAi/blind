# blind

Make any document set blind to the identities you choose. An analyst proposes
a spec, you review it, a deterministic engine applies it, and an independent
auditor checks the result.

Status: pre-release scaffold (0.0.0). Every command is a stub that exits 2.

## Privacy

Placeholder: a full privacy statement lands before 0.1.0. In short, blind is
local by default; documents are never sent to a model, and when a remote model
is configured only a user-visible corpus profile leaves the machine.
